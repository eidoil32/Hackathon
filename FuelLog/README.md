# Fuel Log

אפליקציית מעקב תזונה אישית שרצה כ-Artifact ב-claude.ai:
https://claude.ai/artifact/Wk7pqTzScLMwvCgmmmoCDK

- `app/fuel-log.html` – קוד האפליקציה (הגרסה שפורסמה אחרונה)
- `app/foods.json` – מאגר המזון המובנה (137 מאכלים, עברית ואנגלית)
- `tools/build_foods.py` – בונה את `foods.json`
- `tests/` – בדיקות Playwright עם יכולות מדומות
- `.claude/skills/fuel-log/SKILL.md` (בשורש ה-repo) – הוראות מלאות להמשך עבודה עם Claude: מבנה נתונים, פרסום, רישום ארוחות מהצ׳אט. Claude Code טוען אותו אוטומטית

להמשך עבודה בסשן חדש: פתח סשן על ה-repo הזה וכתוב מה אכלת או מה לשנות באפליקציה.
